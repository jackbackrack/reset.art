What We're Building

Reset is a new art nonprofit. We're building the infrastructure artists, curators, and organizers actually need to create and run their own spaces — the tools, knowledge, networks, and models that make it possible.

More art, in more places, by more people. That's the goal.

How we work

We support independent spaces through exhibitions, public programs, and artist development. We build shared systems — then help others replicate them.

What's in progress

Open calls. Exhibition infrastructure. Art placement. Online sales. Popup partnerships.

What's coming

Permanent spaces. More cities. A scalable model that gets stronger the more people use it.

We're early. We're building. Watch this space.
